# Security policy

Do not open a public issue containing keys, browser secrets, QR payloads,
assertions, subjects, display names, cookies, Matrix identifiers, or production
traffic captures.

Report vulnerabilities privately to the pseud0 maintainers. Include only the
minimum redacted reproduction necessary. Rotate any credential accidentally
shared before sending the report.

Supported releases and a private reporting address must be published before the
first public package release.
